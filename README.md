# Misión San Francisco 1

Bitácora del viaje de AdrenAlina y Gabrieloso a San Francisco (18/12/2026 – 04/01/2027).

## Cómo subir fotos de un día
1. Entrar a la carpeta `fotos/` del repositorio.
2. Crear (o abrir) la carpeta del día: `dia-01`, `dia-02`, … `dia-18`.
3. "Add file" → "Upload files" y arrastrar las fotos (jpg, png o webp).
4. Las fotos aparecen solas en el panel "Fotos de días anteriores" desde el día siguiente.

## Archivos
- `index.html`: toda la página (contenido editable arriba del `<script>`).
- `assets/`: imágenes de la página.
